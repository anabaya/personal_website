# Personal Website

Bienvenue sur mon site personnel !
Une application faite avec **Vite + React** pour me présenter :)

---

## ⚙️ Prérequis

- [Node.js](https://nodejs.org/) (version LTS recommandée)
- [Yarn](https://yarnpkg.com/)

---

## 🚀 Installation et éxécution locale

Cloner le projet :

```bash
git clone https://github.com/anabaya/personal_website.git
```

Installer les dépendances :

```bash
yarn install
```

Lancement en local :

```bash
yarn start
```
